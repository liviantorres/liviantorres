### 🚀 Sobre mim

Gosto de **pegar problemas e transformar em software**.

No desenvolvimento, meu foco vai além de fazer algo funcionar: gosto de entender o problema por trás da demanda, organizar a lógica, pensar na experiência de quem vai usar e construir uma solução que realmente simplifique aquele processo.

Sou estudante de **Ciência da Computação na UFC**, no último ano, e atuo com desenvolvimento **Full Stack**, transitando entre frontend, backend, banco de dados e arquitetura.

Atualmente, meu principal projeto é o **SARA**, uma aplicação que estou desenvolvendo no meu TCC para transformar dados acadêmicos em informações que auxiliem na identificação e acompanhamento da retenção estudantil.
